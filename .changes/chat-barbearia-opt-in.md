titulo: Visual de barbearia opcional para o chat de cada organização
---
A configuração da empresa permite ativar o visual de barbearia no Inbox, independentemente do painel. A mudança mantém as conversas, os filtros, os responsáveis e as ações existentes. Organizações que não ativarem continuam com o visual anterior. Desativar a opção restaura a apresentação anterior sem alterar dados de atendimento.
